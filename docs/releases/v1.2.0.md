## What's new / 更新內容

**繁體中文**
- 面板圓圈裡多了一台跟著速度稱號換車的發光線條載具：從步行、自行車起步，一路到紅線時的火箭，起步、換車都有專屬動畫。
- 速度稱號改成交通工具（步行 → 自行車 → … → 高鐵 → 戰鬥機 → 火箭），門檻隨紅線等比例調整，設定裡可即時看到每個稱號的速度。
- 新增「用量歷史」視窗：每天的輸出與輸入 token、請求數、平均速度與峰值，可依來源、任意日期區間繪圖並匯出 CSV；只保存每日彙總，工具刪掉舊紀錄也不會消失。
- 新增 OpenCode 與 Gemini CLI 來源；Codex 封存與壓縮過的舊紀錄也會納入統計。
- 速度為 0 時改顯示「–」，等待工具時顯示沙漏；展開 agent 清單不再閃爍。
- macOS 26 以上採用 Liquid Glass 外觀；大數字改用 B（十億）單位。

**简体中文**
- 面板圆圈里多了一台跟着速度称号换车的发光线条载具：从步行、自行车起步，一路到红线时的火箭，起步、换车都有专属动画。
- 速度称号改成交通工具（步行 → 自行车 → … → 高铁 → 战斗机 → 火箭），门槛随红线等比例调整，设置里可实时看到每个称号的速度。
- 新增「用量历史」窗口：每天的输出与输入 token、请求数、平均速度与峰值，可按来源、任意日期区间绘图并导出 CSV；只保存每日汇总，工具删掉旧记录也不会消失。
- 新增 OpenCode 与 Gemini CLI 来源；Codex 归档与压缩过的旧记录也会纳入统计。
- 速度为 0 时改显示「–」，等待工具时显示沙漏；展开 agent 列表不再闪烁。
- macOS 26 以上采用 Liquid Glass 外观；大数字改用 B（十亿）单位。

**English**
- The dashboard orb now carries a glowing line drawing of your speed title's vehicle — from a walker and a bicycle pushing off to a rocket at the redline — with its own start-up and hand-over animations.
- Speed titles are now vehicles (Walking → Bicycle → … → Bullet Train → Fighter Jet → Rocket); they scale with the redline, and Settings shows every threshold live.
- New Usage History window: daily output and input tokens, requests, average speed and peak, charted by source over any date range, with CSV export. Only daily totals are kept, so history survives when tools delete old logs.
- New sources: OpenCode and Gemini CLI. Archived and compressed Codex logs now count too.
- Idle speeds show "–" (an hourglass while tools run) instead of 0; expanding the agents list no longer flickers.
- Liquid Glass on macOS 26 and later; large numbers use a B (billion) unit.

**日本語**
- ダッシュボードのメーター内で、スピード称号に合わせた光る線画の乗り物が走ります。徒歩・自転車の発進からレッドラインのロケットまで、発進や乗り換えにも専用アニメーション。
- スピード称号が乗り物に（徒歩 → 自転車 → … → 新幹線 → 戦闘機 → ロケット）。しきい値はレッドラインに比例し、設定画面で各称号の速度をリアルタイムに確認できます。
- 新しい「使用履歴」ウィンドウ：日ごとの出力・入力トークン、リクエスト数、平均速度とピークを、ソース別・任意の期間でグラフ表示し CSV に書き出せます。保存するのは日ごとの集計だけで、ツールが古い記録を削除しても履歴は残ります。
- 新しいソース：OpenCode と Gemini CLI。Codex のアーカイブ・圧縮済みの記録も集計に含めます。
- 速度 0 は「–」（ツール実行待ちは砂時計）で表示。agent リストを展開してもちらつきません。
- macOS 26 以降は Liquid Glass の外観に。大きな数値は B（十億）単位で表示します。
