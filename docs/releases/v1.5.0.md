## What's new / 更新內容

**繁體中文**
- **排行看板**：新的浮動面板，依即時速度排名所有 agent，子 agent 歸在主 agent 底下。共有玻璃、計時塔、霓虹三種風格，最多可開 4 個。上方副錶顯示智力、思考速度與每秒費用，三項都可以各自開關。
- **智力 v2（任務評分 0–100）**：依工具紀錄評估 agent 是在解題還是在空轉，每個新請求從 0 分開始往上爬。評分有五個面向，滿分合計 100：
  - 驗證成功 40；
  - 錯誤收斂 25；
  - 錯誤恢復 15；
  - 行為效率 10；
  - 驗證完整性 10。

  沒有可靠的測試結果時，不會給出完整分數。懸浮窗、選單列／工作列與看板顯示所有 agent 中的最高分。滑鼠停在 agent 列上會出現評分卡，列出五個面向的得分，以及成功、卡住、修復失敗三種預測；預測會用你自己的任務紀錄校準。
- **用量歷史新增「任務表現」**：並排比較 Codex 與 Claude Code，也能逐模型比較。項目包括分數分布、成功率、卡住率、修復失敗率、平均恢復次數與首次通過時間。
- **思考速度**：顯示每秒的思考 token 數，數值為 0 時自動隱藏。
- **推理強度膠囊**：每個 agent 列會顯示目前的推理強度，例如 xhigh、max，以及 Fast／Ultrafast。
- **選單列／工作列**：智力改為獨立開關，可以和網路速度同時顯示。原本選「即時智力」的設定會自動轉換。
- **新增來源**：Pi Coding Agent、OpenClaw、Hermes Agent（#18）與 Factory Droid（#33），共支援 17 種來源。
- **即時上報**：
  - 新增 WebSocket 即時通道並設為預設；服務不支援時會自動改用 HTTP。
  - 每次都完整讀取服務的設定文件。
  - 服務支援時，智力、思考速度與各模型的任務統計會隨「模型」分享一起上報。只送數字，不含任何內容。
- **未定價診斷**（#20）：App 內列出無法計價的模型，提供一鍵複製。價格表升為 v3，新增 Xiaomi MiMo V2.6 與 GPT-6.1 Terra。
- **Windows 工作列**：顯示區塊可以拖動位置，也可以在設定中重設（#23）。

**English**
- **Ranking boards.** A new floating panel ranks every agent by live speed, with sub-agents grouped under their root agent.
  - Three styles: glass, timing tower and neon. Up to four boards.
  - A sub-gauge shows IQ, thinking rate and cost per second. Each can be switched on or off.
- **IQ v2, a 0–100 task score.** It tells from the tool record whether an agent is solving the problem or going in circles. Every new request starts at 0 and climbs with evidence of progress. Five parts make up the 100:
  - verification success, 40;
  - error convergence, 25;
  - recovery, 15;
  - efficiency, 10;
  - verification completeness, 10.

  Without reliable test results the score never claims to be complete. Orbs, the menu bar or taskbar, and boards show the highest score among your agents. Hover an agent row to see the score card: the five parts, plus success, stall and fix-failure predictions calibrated on your own task history.
- **Task performance in Usage History.** Compares Codex and Claude Code side by side, and model by model: score distribution, success, stall and fix-failure rates, attempts to recover, and time to first pass.
- **Thinking rate.** Thinking tokens per second, hidden while it reads 0.
- **Reasoning effort capsule.** Each agent row shows its current effort (such as xhigh or max) and Fast/Ultrafast.
- **Menu bar and taskbar.** IQ now has its own switch and can show beside the network speed. A previous "Live IQ" choice is migrated automatically.
- **New sources.** Pi Coding Agent, OpenClaw, Hermes Agent (#18) and Factory Droid (#33), for 17 sources in total.
- **Live reporting.**
  - The new WebSocket live transport is the default. It falls back to HTTP automatically when a service doesn't support it.
  - The service's discovery document is always fetched in full.
  - Where a service supports it, IQ, thinking rate and per-model task statistics are reported along with model sharing. Numbers only, never content.
- **Unpriced diagnostics (#20).** The app lists the models it can't price, with a copy button. Price table v3 adds Xiaomi MiMo V2.6 and GPT-6.1 Terra.
- **Windows taskbar widget.** You can drag it to another position, and reset it in Settings (#23).

**日本語**
- **ランキングボード**：エージェントをリアルタイム速度で順位付けする新しいフローティングパネルです。サブエージェントは親エージェントの下にまとまります。
  - スタイルはガラス、タイミングタワー、ネオンの 3 種類で、最大 4 枚まで表示できます。
  - サブゲージには知能、思考速度、毎秒の費用が表示され、それぞれ切り替えられます。
- **知能 v2（タスクスコア 0〜100）**：ツールの記録から、エージェントが問題を解いているのか空回りしているのかを評価します。新しいリクエストごとに 0 から始まり、進捗の証拠に応じて上がります。スコアは次の 5 項目で構成され、合計 100 点です。
  - 検証成功 40
  - エラー収束 25
  - 回復 15
  - 効率 10
  - 検証の網羅性 10

  確かなテスト結果がないときは、満点の評価はしません。フローティングウィンドウ、メニューバー／タスクバー、ボードには、全エージェント中の最高スコアを表示します。行にカーソルを合わせると評価カードが開き、5 項目の得点と、成功・停滞・修正失敗の予測を表示します。予測は自分のタスク履歴で校正されます。
- **使用履歴に「タスクの成績」を追加**：Codex と Claude Code を並べて、またモデルごとに比較できます。比較項目はスコア分布、成功率、停滞率、修正失敗率、回復までの試行回数、初回合格までの時間です。
- **思考速度**：毎秒の思考トークン数を表示します。0 の間は非表示になります。
- **推論強度カプセル**：各エージェント行に、現在の推論強度（xhigh、max など）と Fast／Ultrafast を表示します。
- **メニューバー／タスクバー**：知能を独立したスイッチにし、ネットワーク速度と同時に表示できるようにしました。以前の「リアルタイム知能」の設定は自動で移行されます。
- **新しいソース**：Pi Coding Agent、OpenClaw、Hermes Agent（#18）、Factory Droid（#33）に対応し、合計 17 ソースになりました。
- **リアルタイム送信**：
  - WebSocket のリアルタイム通信を追加し、既定にしました。サービスが対応していない場合は自動で HTTP を使います。
  - サービスの設定文書は毎回すべて取得します。
  - 対応サービスには、モデル共有と一緒に、知能、思考速度、モデルごとのタスク統計を送信します。送るのは数値だけで、内容は一切含みません。
- **未価格診断（#20）**：価格を付けられないモデルをアプリ内に一覧表示し、ワンクリックでコピーできます。価格表は v3 になり、Xiaomi MiMo V2.6 と GPT-6.1 Terra を追加しました。
- **Windows のタスクバー**：表示ブロックをドラッグして移動でき、設定でリセットできます（#23）。
