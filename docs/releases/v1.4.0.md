## What's new / 更新內容

**繁體中文**
- 新增 ZCode、Kimi Code CLI 與 Grok Build 的實際資料收集，並將 DeepSeek Harness 統一命名為 DSH；macOS 與 Windows 共支援 13 種來源。
- 執行模式：依各工具可確認的資料顯示 Standard、Fast、Ultrafast，以及原生加速器、模型變體與路由選擇。設定預設值與實際回應分開呈現；無法確認時保留未知。用量歷史新增模式分類及獨立 CSV，沿用原有速度計算公式。
- API 擴充支援各模型的 Harness 請求數、執行模式、頭像與多設備身分；依接收端公告的能力啟用，並相容舊版服務。
- 頭像與使用者名稱整合在「設定 → API」同一張個人資料卡，可預覽、更新或移除頭像。
- 多設備透過一次性配對碼及已綁定設備核准，合併至同一身分；每台設備保留自己的金鑰與上報序列。解除綁定不影響已入帳歷史。
- LED 懸浮窗新增絲綢流動核心、日冕、速度光跡與數字閃電效果，並改善 GPU 繪製；儀表板只列出今天有輸出的來源。

**简体中文**
- 新增 ZCode、Kimi Code CLI 与 Grok Build 的实际数据采集，并将 DeepSeek Harness 统一命名为 DSH；macOS 与 Windows 共支持 13 种来源。
- 执行模式：根据各工具可确认的数据展示 Standard、Fast、Ultrafast，以及原生加速器、模型变体与路由选择。配置默认值与实际响应分开展示；无法确认时保留未知。用量历史新增模式分类及独立 CSV，沿用原有速度计算公式。
- API 扩展支持各模型的 Harness 请求数、执行模式、头像与多设备身份；按接收端声明的能力启用，并兼容旧版服务。
- 头像与用户名整合在「设置 → API」同一张个人资料卡，可预览、更新或移除头像。
- 多设备通过一次性配对码及已绑定设备批准，合并至同一身份；每台设备保留自己的密钥与上报序列。解除绑定不影响已入账历史。
- LED 悬浮窗新增丝绸流动核心、日冕、速度光迹与数字闪电效果，并改善 GPU 绘制；仪表盘只列出今天有输出的来源。

**English**
- Added real data collection for ZCode, Kimi Code CLI and Grok Build, and standardized the DeepSeek Harness name as DSH. Both macOS and Windows now support 13 sources.
- Execution modes show confirmed Standard, Fast and Ultrafast tiers, plus native accelerator, model-variant and routing choices. Configured defaults remain separate from response evidence, and unconfirmed modes remain unknown. Usage History adds mode breakdowns and a separate CSV without changing speed formulas.
- Optional API extensions add per-model Harness request counts, execution modes, avatars and shared identities. Features follow receiver-advertised capabilities and remain compatible with older services.
- Avatar and username now share one profile card in Settings → API, with avatar preview, replacement and removal.
- Link devices with a one-time pairing code approved by an existing device. Each device keeps its own key and report sequence; unlinking preserves already-accounted history.
- The LED orb adds a flowing silk core, corona, speed streaks and digit lightning, with GPU rendering improvements. The dashboard lists only sources that produced output today.

**日本語**
- ZCode、Kimi Code CLI、Grok Build の実データ収集に対応し、DeepSeek Harness の名称を DSH に統一。macOS と Windows で 13 種類のソースを利用できます。
- 実行モードでは確認できた Standard・Fast・Ultrafast、および各ツール固有のアクセラレーター、モデル派生、ルーティング設定を表示します。設定の既定値と実際の応答情報を区別し、確認できない値は不明のまま扱います。速度の計算式は変えず、使用履歴にモード別集計と専用 CSV を追加しました。
- API 拡張でモデル別 Harness リクエスト数、実行モード、アバター、複数デバイスの共通 ID に対応。受信側が公開する対応機能に従って有効化し、旧サービスとも互換性を保ちます。
- 「設定 → API」の同じプロフィールカードにアバターとユーザー名をまとめ、画像のプレビュー・変更・削除ができます。
- ワンタイムコードと既存デバイスの承認でデバイスを連携。各デバイスの鍵と送信シーケンスは独立し、連携解除後も計上済みの履歴は保持します。
- LED オーブにシルク状のコア、コロナ、光の軌跡、数字の稲妻を追加し、GPU 描画を改善。ダッシュボードには今日出力のあったソースだけを表示します。

Live reporting and profile features remain optional. Avatars and device pairing require a compatible API service.
