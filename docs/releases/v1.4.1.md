## What's fixed / 修正內容

**繁體中文**

- 修正 DSH 模型 `deepseek-v4.1-flash-1017` 無法辨識、導致 API 等值費用未計價的問題，現在會對應至既有的 `deepseek-flash`。
- 修正 Antigravity 只有 `Gemini 3.8 Flash` 或 `Gemini 4 Argon` 顯示名稱時的計價；原有模型 ID 仍優先使用。
- 共用價格表升為 v2，沿用原有價格、歷史期間、離峰及快取規則；真正未知或缺少模型資訊的請求仍標為未計價。
- macOS 與 Windows 安裝包均內附新表；既有版本也可在開啟網路連線時，透過「設定 → 費用」檢查價格表更新或等候自動同步。

先前未計價的本機紀錄可依現有保留資料重新計價，但不保證完整補回已遺漏的排行榜費用，也不會猜測或改寫接收端歷史。

**简体中文**

- 修复 DSH 模型 `deepseek-v4.1-flash-1017` 无法识别、导致 API 等值费用未计价的问题，现会对应已有的 `deepseek-flash`。
- 修复 Antigravity 只有 `Gemini 3.8 Flash` 或 `Gemini 4 Argon` 显示名称时的计价；原有模型 ID 仍优先使用。
- 共用价格表升为 v2，沿用原有价格、历史区间、非高峰及缓存规则；真正未知或缺少模型信息的请求仍标为未计价。
- macOS 与 Windows 安装包均内附新表；已有版本也可在开启网络连接时，通过「设置 → 费用」检查价格表更新或等待自动同步。

先前未计价的本机记录可依据现有保留数据重新计价，但不保证完整补回已遗漏的排行榜费用，也不会猜测或改写接收端历史。

**English**

- Fixed the DSH model `deepseek-v4.1-flash-1017` resolving as unknown and remaining unpriced; it now maps to the existing `deepseek-flash` entry.
- Fixed pricing when Antigravity supplies only the plain display name `Gemini 3.8 Flash` or `Gemini 4 Argon`. A supplied response model ID still takes precedence.
- Price table v2 preserves all existing prices, historical periods, off-peak and cache rules. Unsupported or missing model metadata remains explicitly unpriced.
- macOS and Windows packages include the new table. Existing clients can also use Settings → Cost to check for a price-table update, or wait for automatic sync, with Network Access enabled.

Previously unpriced local records can be priced where retained data permits. This does not guarantee full recovery of omitted leaderboard costs or guess and rewrite receiver history. Fixes [#10](https://github.com/zoefix/agent-speed/issues/10).

**日本語**

- DSH の `deepseek-v4.1-flash-1017` が不明なモデルとなり、API 換算費用を計算できない問題を修正。既存の `deepseek-flash` に対応付けます。
- Antigravity が `Gemini 3.8 Flash` または `Gemini 4 Argon` の表示名だけを記録する場合の費用計算を修正。応答のモデル ID がある場合は引き続き優先します。
- 共通価格表を v2 に更新。既存の価格、過去の期間、オフピーク、キャッシュ規則は保持し、未対応またはモデル情報のないリクエストは未計算のまま表示します。
- macOS・Windows の配布ファイルに新しい表を同梱。既存クライアントもネットワーク接続を有効にして「設定 → 費用」から価格表を確認するか、自動同期を利用できます。

保持されているローカルデータに基づき、以前計算できなかった費用を再計算できます。ただし、ランキングに未送信だった費用の完全な回復は保証せず、推測による受信側の履歴変更も行いません。
