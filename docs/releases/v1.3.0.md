## What's new / 更新內容

**繁體中文**
- 新增來源：omp（oh-my-pi）、Google Antigravity、騰訊 WorkBuddy（中國版）與 WorkBuddy AI（國際版）。
- 看得到花費：tok/s 之外，也能即時看每秒花多少錢。預設美元，共支援 38 種貨幣（每天更新匯率）；金額以各模型官方 API 牌價估算，月費訂閱的來源可標記後排除。面板顯示今日費用，用量歷史記錄每天的費用；價格表每天從 GitHub 自動更新。
- 網路流量：懸浮窗以兩行小字顯示各 agent 或整台電腦的上傳／下載速度，選單列／工作列與面板也看得到，用量歷史記錄每天的流量。Windows 若要看各 agent 的流量，需要安裝一次選用的小型輔助服務（需系統管理員同意）。
- 懸浮窗：五種樣式（LED 儀表、指針轉速錶、能量液球、反應爐、極簡圓環），可同時開多個並自由組合來源，下方附玻璃名牌；Windows 改用 Direct3D 繪製，CPU 用量大幅降低。
- 稱號：九種主題（交通工具、動物、蒲福風級、宇宙、修真境界、武學境界、魔法位階、遊戲段位、工程師職涯），另可自訂最多 8 組；選交通工具以外的主題時，面板圓圈改顯示發光的稱號徽章。
- 選單列／工作列可選擇顯示 tok/s、金額，或 tok/s＋金額（即時花費與今日總額）。
- 用量歷史新增「今天」「昨天」，可看各模型的速度，圖表可切換費用與網路流量，CSV 也一併匯出。
- 即時上報到 API（選用，預設關閉；面板會詢問一次）：可把即時數字分享給你選的服務，例如 Codex Radar 的速蹬天梯。只傳送即時數字（速度、token 數、各工具的明細、以美元計的 API 等值費用、agent 的網路流量、使用中的模型與稱號等級），以你取的使用者名稱上報，並用只存在這台電腦上的金鑰簽章；從不傳送對話內容、檔案、專案名稱或歷史紀錄，隨時可以暫停或關閉。
- 設定 → 關於新增「網路連線」總開關，一鍵關閉所有連網功能。
- 其他修正：用量歷史的卡片標題與隱私說明不再被截斷；設定與選單排版更整齊；紅線預設改為滑桿最大值。

**English**
- New sources: omp (oh-my-pi), Google Antigravity, Tencent WorkBuddy (China edition) and WorkBuddy AI (international edition).
- See what it costs: next to tok/s you can watch the money per second, live. US dollars by default, 38 currencies in all, with daily exchange rates. Costs are estimated at each model's official API list prices, and sources on a flat-rate subscription can be marked and left out. The dashboard shows today's cost, Usage History keeps each day's cost, and the price table updates itself daily from GitHub.
- Network traffic: the orbs show upload and download speed — per agent or for the whole computer — as two small lines, and so can the menu bar / taskbar and the dashboard; Usage History keeps each day's traffic. On Windows, per-agent traffic needs a small optional helper service, installed once with administrator approval.
- Floating orbs: five styles (LED Gauge, Needle Tachometer, Liquid Energy, Reactor, Minimal Ring), as many orbs as you like with any mix of sources, and glass name plates under them. On Windows the orbs now draw with Direct3D and use far less CPU.
- Titles: nine themes (Vehicles, Animals, Beaufort Scale, Cosmos, Cultivation, Martial Arts, Arcane Ranks, Game Ranks, Engineer Career) plus up to 8 title sets of your own; with any theme other than Vehicles, the dashboard orb shows a glowing title badge.
- The menu bar / taskbar can show tok/s, money, or tok/s + money (the live rate over today's total).
- Usage History adds Today and Yesterday, shows each model's speed, and charts cost and network traffic too; all of it goes into the CSV.
- Live reporting to an API (optional, off by default; the dashboard offers it once): share your live numbers with a service you pick, such as the Codex Radar speed ladder. Only live numbers are sent — speed, token counts, a per-tool breakdown, API-equivalent cost in US dollars, your agents' network traffic, the models in use and your title level — under a username you choose, signed with a key that never leaves your computer. Never conversation content, files, project names or history. Pause or turn it off at any time.
- Settings → About has a new Network Access switch that turns every network connection off at once.
- Fixes: history card titles and the privacy note are no longer cut off; tidier settings and menus; the redline now defaults to the slider's maximum.

**日本語**
- 新しいソース：omp（oh-my-pi）、Google Antigravity、Tencent WorkBuddy（中国版）と WorkBuddy AI（国際版）。
- 費用が見える：tok/s に加えて、1 秒あたりの金額もリアルタイムに表示できます。初期設定は米ドルで、全 38 通貨から選べます（為替レートは毎日更新）。金額は各モデルの公式 API 定価で見積もり、定額プランで使うソースはサブスクとして除外できます。ダッシュボードに今日の費用、使用履歴に日ごとの費用を表示し、価格表は GitHub から毎日自動で更新されます。
- 通信量：オーブに agent ごと、またはコンピューター全体のアップロード／ダウンロード速度を小さな 2 行で表示。メニューバー／タスクバーとダッシュボードにも表示でき、使用履歴に日ごとの通信量を記録します。Windows で agent ごとの通信量を見るには、任意の小さなヘルパーサービスを一度だけインストールします（管理者の承認が必要）。
- フローティングオーブ：5 つのスタイル（LED ゲージ、針式タコメーター、リキッドエナジー、リアクター、ミニマルリング）。オーブはいくつでも置けて、ソースを自由に組み合わせられ、下にガラスのネームプレートが付きます。Windows では Direct3D で描画するようになり、CPU 使用率が大きく下がりました。
- 称号：9 つのテーマ（乗り物、動物、風力階級、宇宙、仙道修行、武芸の道、魔法の位階、ゲームランク、エンジニアの道）と、最大 8 個のカスタム称号。乗り物以外のテーマでは、ダッシュボードのメーターに光る称号バッジが表示されます。
- メニューバー／タスクバーの表示を tok/s、金額、tok/s＋金額（現在の金額と今日の合計）から選べます。
- 使用履歴に「今日」「昨日」を追加。モデルごとの速度を表示し、費用と通信量のグラフにも切り替えられます。CSV にもすべて書き出します。
- API へのライブ送信（任意・初期設定はオフ。ダッシュボードで一度だけ案内します）：Codex Radar のスピードランキングなど、選んだサービスにライブの数値を共有できます。送るのはライブの数値だけ（速度、トークン数、ツールごとの内訳、米ドル建ての API 換算費用、agent の通信量、使用中のモデル、称号のレベル）で、選んだユーザー名で送り、このコンピューターから出ない鍵で署名します。会話の内容、ファイル、プロジェクト名、履歴は一切送りません。いつでも一時停止・オフにできます。
- 設定 → 情報に「ネットワーク接続」のスイッチを追加。すべての通信を一度にオフにできます。
- 修正：使用履歴のカード見出しとプライバシーの注記が途中で切れなくなりました。設定とメニューのレイアウトを整え、レッドラインの初期値をスライダーの最大値にしました。
