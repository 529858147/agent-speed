## What's new / 更新內容

**繁體中文**
- 新增 DeepSeek Harness（dsh）來源：桌面版與命令列的速度、用量與子 agent 都會即時顯示。
- Agent 清單依主 agent 分組，子 agent 緊接在主 agent 下方；清單可一鍵展開全部或收合。
- 面板只顯示本機偵測得到的來源；安裝程式在慢速網路下會顯示進度並自動重試。

**简体中文**
- 新增 DeepSeek Harness（dsh）来源：桌面版与命令行的速度、用量与子 agent 都会实时显示。
- Agent 列表按主 agent 分组，子 agent 紧跟在主 agent 下方；列表可一键展开全部或收起。
- 面板只显示本机检测到的来源；安装程序在慢速网络下会显示进度并自动重试。

**English**
- New source: DeepSeek Harness (dsh), desktop app and CLI, including sub-agents.
- Agents are grouped under their parent, and the list can expand to show everyone.
- The dashboard lists only the sources found on your computer; installers show progress and retry on slow networks.

**日本語**
- 新しいソース：DeepSeek Harness（dsh）。デスクトップ版と CLI、サブ agent にも対応。
- Agent はメイン agent ごとにまとまり、リストはすべて展開できます。
- ダッシュボードには検出されたソースだけを表示。インストーラーは進捗を表示し、遅い回線でも自動で再試行します。
